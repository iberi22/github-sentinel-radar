# Security Policy

## Supported Versions

Only the latest release (or the default branch `main`) is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

Please report vulnerabilities privately via GitHub Security Advisories by clicking the "Report a vulnerability" button on this repository. **Do not open public issues for security reports.**

Do not mention or speculate about any specific vulnerabilities in public forums or issues.

## Response Targets

- **Acknowledgment:** Within 5 business days.
- **Status Update:** Within 14 days.
- **Disclosure:** We follow coordinated disclosure practices.
- **Bug Bounty:** Currently, there is no bug bounty program.
