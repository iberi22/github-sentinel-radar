## 🌟 মূল বৈশিষ্ট্যসমূহ

1. **🛡️ অ্যান্টি-বট সেন্টিনেল শিল্ড**: ভুয়া ফলোয়ার এবং স্প্যাম প্রোফাইল স্বয়ংক্রিয়ভাবে সনাক্ত ও ব্লক করে।
2. **📡 অন-ডিমান্ড টেক রাডার**: আপনার পছন্দের রিপোজিটরির সর্বশেষ রিলিজ এবং স্ট্যাকের সাথে মানানসই নতুন প্রকল্প উপস্থাপন করে।
3. **⚡ সম্পদ সাশ্রয় ও হাইবারনেশন**: ভারী স্ক্যানিং শুধুমাত্র ব্যবহারকারীর নির্দেশে সম্পন্ন হয় এবং ৭ দিন নিষ্ক্রিয় থাকলে স্থগিত থাকে।
4. **🌐 বর্ডারলেস বহুভাষিক ইন্টারফেস**: বর্ডারবিহীন আধুনিক ডিজাইন, ডার্ক/লাইট মোড এবং বিশ্বের শীর্ষ ১০টি ভাষার জন্য পূর্ণ সমর্থন।
5. **🤝 যাচাইকৃত ডেভেলপার নেটওয়ার্ক**: আসল নির্মাতাদের যুক্ত করার একটি উন্মুক্ত Git-ভিত্তিক ডাটাবেস।
6. **🔍 পর্যালোচনা তালিকা (মানব সিদ্ধান্ত)**: ফলোয়ার ও ফলোয়িংকে ট্রাস্ট % সহ বিশ্বস্ত/সম্ভাব্য বট তালিকায় ভাগ করে। অটো-ব্লক নেই: টিক দিন, কপি করে ওয়ার্কফ্লো দিয়ে ব্লক করুন। শুধুমাত্র স্বয়ংক্রিয়ভাবে তৈরি ব্লক-রিকোয়েস্ট PR মার্জ করলেই ব্লক কার্যকর হয়।

## 🚀 দ্রুত সেটআপ (২ মিনিটে ফর্ক করুন)

1. **Use this template** দিয়ে নিজের পাবলিক রিপোজিটরি তৈরি করুন।
2. প্রয়োজনে Actions চালু করুন। Settings → Pages-এ **GitHub Actions** বাছুন এবং **Deploy GitHub Pages** একবার চালান।
3. ড্যাশবোর্ডে আপডেট চাপুন, GitHub-এ **Run workflow** নিশ্চিত করে ফিরুন। **ব্রাউজার টোকেন বা রাডারের অতিরিক্ত সিক্রেট লাগবে না।**
4. ব্যক্তিগত ব্লকিং ঐচ্ছিক: [Sentinel সেটআপ](DEPLOYMENT.md#sentinel)।
