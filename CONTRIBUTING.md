# Contributing

Thank you for your interest in contributing!

## How to Contribute

1. **Fork the repository** on GitHub.
2. **Create a new branch** for your feature or bugfix.
3. Make your changes and commit them using **Conventional Commits** (e.g., `feat: add new feature`, `fix: resolve issue`).
4. **Run the tests** locally before opening a pull request to ensure everything is working correctly.
5. Open a pull request against the `main` branch.

We appreciate your contributions!
