> **موجز معلومات تقنية عند الطلب، درع حماية ضد حسابات الروبوت الوهمية، وشبكة مطورين موثوقة.**
> مصمم بهندسة طبقات بسيطة وغير معقدة تعمل بالكامل مجاناً عبر GitHub Actions و GitHub Pages.

---

## 🌟 أبرز المميزات

1. **🛡️ درع حماية الحساب**: حظر فوري للحسابات الروبوتية الوهمية ومحاولات التلاعب بتواريخ المساهمات.
2. **📡 رادار تقني عند الطلب**: استكشاف أحدث إصدارات الأدوات المفضلة ومشاريع واعدة تناسب اهتماماتك البرمجية.
3. **⚡ كفاءة الموارد والسبات التلقائي**: لا استهلاك غير مبرر للخدمة؛ يعمل البحث الثقيل عند الطلب فقط ويدخل في وضع السبات بعد 7 أيام من عدم النشاط.
4. **🌐 واجهة حديثة بدون حواف (Borderless)**: تصميم أنيق وعصري يدعم الوضعين الليلي والنهاري ودعم كامل لـ 10 لغات عالمية تشمل دعم العربية (RTL).
5. **🤝 شبكة الثقة اللامركزية**: قاعدة بيانات مجتمعية مبنية على جيت لتوثيق المطورين الحقيقيين والمشاريع المفتوحة.
6. **🔍 قائمة المراجعة (قرار بشري)**: تصنّف المتابِعين والمتابَعين إلى موثوقين/بوتات محتملة مع نسبة ثقة وأسباب وروابط. لا حظر تلقائي: حدّد وانسخ واحظر عبر سير العمل.

---

## 🚀 التثبيت السريع في دقيقتين

1. أنشئ مستودعك العام عبر **Use this template**.
2. فعّل Actions عند الطلب، واختر **GitHub Actions** في Settings → Pages، ثم شغّل **Deploy GitHub Pages** مرة واحدة.
3. افتح اللوحة واضغط تحديث، ثم أكّد **Run workflow** في GitHub وعد. **لا رمز في المتصفح ولا سر إضافي للرادار.**
4. الحظر الشخصي اختياري: [إعداد Sentinel](DEPLOYMENT.md#sentinel).
