## 🌟 اہم خصوصیات

1. **🛡️ اینٹی بوٹ سنٹینل شیلڈ**: جعلی فالورز اور سپیم بوٹس کا خودکار پتہ لگانا اور بلاک کرنا۔
2. **📡 آن ڈیمانڈ ٹیک راڈار**: آپ کے پسندیدہ ذخائر سے نئے ریلیز اور اسٹیک سے مطابقت رکھنے والے پروجیکٹس کی دریافت۔
3. **⚡ وسائل کی بچت اور ہائبرنیشن**: بھاری اسکیننگ صرف آپ کی مانگ پر ہوتی ہے اور 7 دن غیر فعال رہنے پر رک جاتی ہے۔
4. **🌐 بارڈر لیس کثیر لسانی انٹرفیس**: جدید ڈیزائن، ڈارک/لائٹ موڈ اور دنیا کی 10 بڑی زبانوں بشمول اردو (RTL) کے لیے مکمل سپورٹ۔
5. **🤝 تصدیق شدہ ڈویلپر نیٹ ورک**: حقیقی تخلیق کاروں کو جوڑنے والا ایک غیر مرکزی گٹ ڈیٹا بیس۔

---

## 🚀 فوری آغاز (2 منٹ میں سیٹ اپ)

1. **Use this template** سے اپنی عوامی ریپوزٹری بنائیں۔
2. ضرورت پر Actions فعال کریں۔ Settings → Pages میں **GitHub Actions** منتخب کریں اور **Deploy GitHub Pages** ایک بار چلائیں۔
3. ڈیش بورڈ میں اپ ڈیٹ دبائیں، GitHub پر **Run workflow** کی تصدیق کرکے واپس آئیں۔ **براؤزر ٹوکن یا رڈار کا اضافی سیکرٹ نہیں چاہیے۔**
4. ذاتی بلاکنگ اختیاری ہے: [Sentinel سیٹ اپ](DEPLOYMENT.md#sentinel)۔
