> **Flux de veille technologique à la demande, bouclier anti-bot et réseau de développeurs vérifiés.**
> Conçu selon une philosophie de couches modulaires simples, hébergé gratuitement sur GitHub Actions et Pages.

## 🌟 Fonctionnalités Clés

1. **🛡️ Bouclier Anti-Bot** : Détection et blocage automatique des fermes d'abonnés et des profils frauduleux.
2. **📡 Radar Technologique à la Demande** : Suivi des dernières versions de vos outils favoris et découvertes de projets adaptés à votre pile technique.
3. **⚡ Économie d'Énergie et Hibernation** : L'analyse fonctionne **à la demande**. Elle se met en pause après 7 jours d'inactivité.
4. **🌐 Interface Borderless Multilingue** : Design épuré sans bordures dures, mode clair/sombre et support complet des 10 langues les plus parlées.
5. **🤝 Réseau de Confiance Décentralisé** : Répertoire communautaire appuyé sur Git pour valoriser les projets réels.

---

## 🚀 Déploiement Rapide en 2 Minutes

1. Créez votre dépôt public avec **Use this template**.
2. Activez Actions si demandé. Dans Settings → Pages choisissez **GitHub Actions**, puis lancez **Deploy GitHub Pages** une fois.
3. Ouvrez le tableau de bord, actualisez, confirmez **Run workflow** sur GitHub et revenez. **Aucun jeton dans le navigateur ni secret supplémentaire pour le radar.**
4. Le blocage personnel est facultatif : [configuration Sentinel](DEPLOYMENT.md#sentinel).
